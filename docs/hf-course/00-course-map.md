# 如何使用 Hugging Face Agents Course 学习 Agent

这套课程从 Agent 的基本构成讲起，再让你亲手接工具、观察运行轨迹，最后进入框架实践和项目挑战。你不需要先掌握某一个框架，但最好能读懂基础 Python，并知道大语言模型接收输入、生成输出的大致过程。Unit 1 会把后者再讲一遍。

## 课程原本怎样安排

Hugging Face 把课程分成准备、基础、框架、应用和最终挑战。Unit 0 帮你准备 Hugging Face 账户与学习环境；Unit 1 解释模型、消息、工具以及思考—行动—观察循环，并完成第一个 Agent；Unit 2 分别练习 smolagents、LangGraph 和 LlamaIndex；后续单元做应用与基准挑战。扩展单元还涉及函数调用模型微调、Agent 可观测性与评估，以及游戏 Agent。

| 阶段 | 要学会的事 | 可交付的练习 |
| --- | --- | --- |
| 准备 | 账户、推理方式、Python 环境 | 能安全配置模型访问 token |
| 基础 | 模型怎样读消息，工具怎样执行，结果怎样回填 | 手写最小 Agent，并识别伪造的观察 |
| 框架 | 用三个框架表达 Agent 与工作流 | 能运行和修改框架示例 |
| 应用 | 把能力用于一项真实任务 | 明确目标、工具、失败处理和验收 |
| 挑战 | 用基准或题集比较实现 | 保存结果与失败案例，而非只展示成功截图 |

可以先按每周约 3–4 小时完成一个章节来安排。代码练习、服务额度与调试时间因人而异，不需要为了赶节奏略过运行轨迹。每完成一课，最好能说清「模型决定了什么、程序做了什么、结果如何验证」。

## 自学、社区与认证

这套学习材料支持自由自学，也曾提供测验、作业、最终挑战和证书路径。旧版认证截止日期是 **2025 年 7 月 1 日**；这只是历史信息，不能作为 2026 年仍可申请证书的承诺。若你关心证书，请在活动页面核对当前规则。对于求职准备，更值得保留的是可复现的项目、失败样例和设计解释。

课程提供 GitHub 仓库、Hugging Face Hub 组织和 Discord 社区。你可以在 Hub 看配套 Space 与 Notebook，在 GitHub 报告课程代码问题、提出修改；Discord 适合找同学讨论。参与社区是可选的，不是完成本站技术文章的前提。

本网站的文章按「先原理、再手工实现、再框架」重排，正文已经承接主要内容。示例的在线可视化、Space、Notebook 和挑战仍以文末来源链接保留；如果某个外部服务不可用，你仍能通过文章中的消息、代码与练习理解核心机制。

## 从哪里开始

如果你刚接触 Agent，先读「AI Agent 到底是什么」，再按顺序走完模型、消息、工具、循环和手写最小 Agent；这几篇能避免你把框架 API 当成 Agent 原理。已有项目经验的读者可以先跑「第一个 smolagents Agent」，遇到工具调用、消息格式或伪造结果的问题时回到对应基础课。之后根据工作任务选择 smolagents、LangGraph 或 LlamaIndex 的实践线。

每学完一篇，给自己做两个检查：能否不看文章解释这一步的输入与输出；能否在示例里故意制造一个失败并说清程序应如何处理。如果只跑通顺利案例，真实任务中的权限、空结果和超时仍会让系统停下来。
